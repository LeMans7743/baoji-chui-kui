# 包記炊粿

手機橫向（約 16:9）觸控單關衝分小遊戲。場景：包記灶間。口號：顧粿沒那麼簡單。

## 怎麼打開

1. 用本機靜態伺服器開啟專案資料夾（勿直接用 `file://`，部分瀏覽器會擋素材）：
   ```bash
   cd /workspace/baoji-chui-kui
   python3 -m http.server 8765
   ```
2. 在手機或桌面瀏覽器打開：`http://localhost:8765/`（或該機器 IP）。
3. **請橫拿手機**。直向時會提示旋轉，不會改成直式版面。

桌面可把視窗拉成橫向比例，用滑鼠點按／按住模擬觸控。

## 操作

- **倒漿**：點空的蒸籠開始煮。
- **搧火**：按住（或點）右側扇子提高火力；火太小會偏生，太大容易微焦／焦毀並觸發突發事件。
- **揭籠**：點正在煮的蒸籠蓋，依熟度結算（紅心／恰到好處／微焦／生／焦毀／沒揭到）。
- **出餐**：成功揭籠後，在時限內點左側紅籃送出，可拿額外加分。
- 點中央走道可讓包哥走過去；包哥始終面向鏡頭。

一回合 **90 秒**，結束後可登錄連線排行榜（今日／累積）。

## 連線排行榜

- 今日榜與累積榜透過 Firebase Realtime Database 共用（專案 `baoji-chui-kui`）。
- 玩家**不必登入帳號**；僅在回合結束按下「登錄排行榜」時寫入。
- 有填 2–8 字有效名稱時使用該名稱並存成 `playerName`；否則登錄為「訪客」。不會改寫舊紀錄的名字。
- **本機 localStorage 鍵名**：`baoji-chui-kui-save`（只保存 `playerName`；舊版若留有本機榜欄位可忽略）。
