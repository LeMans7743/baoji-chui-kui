# 包記炊粿

手機橫向（約 16:9）觸控單關衝分小遊戲。場景：包記灶間。口號：顧粿沒那麼簡單。

## 怎麼打開

1. 用本機靜態伺服器開啟專案資料夾（勿直接用 `file://`，部分瀏覽器會擋素材）：
   ```bash
   cd /workspace/baoji-chui-kui
   python3 -m http.server 8765
   ```
2. 在手機或桌面瀏覽器打開：`http://localhost:8765/`（或該機器 IP）。
3. **請橫拿手機**。直向時會提示旋轉，不會改成直式版面。

桌面可把視窗拉成橫向比例，用滑鼠點按／按住模擬觸控。

## 操作

- **倒漿**：點空的蒸籠開始煮。
- **搧火**：按住（或點）右側扇子提高火力；火太小會偏生，太大容易微焦／焦毀並觸發突發事件。
- **揭籠**：點正在煮的蒸籠蓋，依熟度結算（紅心 500／恰到好處 200／微焦 50／生、焦毀、沒揭到 0）。
- **連擊**：紅心 +2、恰到好處 +1、微焦不變、生／焦毀／沒揭到／沒打到的蟑螂歸零。倍率 `1 + 0.1×連擊`，上限 ×5。連擊跨過 5／10／15 各領一次 500／1000／2000（+2 可以一次跨過門檻）。
- **神手**：連續紅心的第 3、6、9… 籠，該籠底分再 +300。中間不是紅心就重新計。
- **火力全開 ×1.5**：揭開當下（含這一籠）至少 3 籠正在煮，而且這籠是紅心或恰到好處，粿分 ×1.5。
- **出餐**：揭開後 4 秒內仍可送出。前 2 秒平加 100，不乘倍率；超過 2 秒沒有這筆加分。
- **事件**：打中 +50；蟑螂沒打到 −150 並斷連擊；老鼠沒打到 −200，連擊不變。分數不會低於 0。
- **型完好 +50**（沒溢模、而且這籠底分大於 0）的擺放方式還沒定案。目前暫且加進底分，和神手一起乘上連擊與 ×1.5 後再無條件捨去。這不是最終規則。
- **結算評價** S／A／B／C 的門檻（490000／150000／10000）來自這次合成試玩，不是真實玩家百分位。
- 點中央走道可讓包哥走過去；包哥始終面向鏡頭。

一回合 **90 秒**，結束後可登錄連線排行榜（今日／累積）。

## 連線排行榜

- 今日榜與累積榜透過 Firebase Realtime Database 共用（專案 `baoji-chui-kui`）。
- 玩家**不必登入帳號**；僅在回合結束按下「登錄排行榜」時寫入。
- 有填 2–8 字有效名稱時使用該名稱並存成 `playerName`；否則登錄為「訪客」。不會改寫舊紀錄的名字。
- **本機 localStorage 鍵名**：`baoji-chui-kui-save`（只保存 `playerName`；舊版若留有本機榜欄位可忽略）。
